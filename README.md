# منصة حصة آل علي القانونية

منصة قانونية سعودية عامة بإشراف المحامية حصة آل علي، تجمع بين المكتبة القانونية والتوعية النظامية والتعريف بالخدمات المهنية.

موقع عربي RTL للمحامية حصة آل علي، مبني بواجهة ثابتة خفيفة ومتجاوبة مع الجوال.

## تشغيل الموقع
- الصفحة الرئيسية: `index.html`
- يمكن نشر المستودع عبر GitHub Pages من إعدادات المستودع: **Settings → Pages → Deploy from a branch → main → /(root)**.

## قبل الإطلاق العام
يرجى اعتماد وإضافة البيانات التالية:
1. صورة شخصية مهنية أصلية للمحامية.
2. السيرة الذاتية والمؤهلات والخبرات والعضويات المعتمدة.
3. مجالات الممارسة الفعلية التي ترغب المحامية بعرضها.
4. رقم الترخيص المهني بعد التحقق منه، وأي بيانات منشأة أو ترخيص يلزم إظهاره.
5. البريد الرسمي ورقم الهاتف وWhatsApp وعنوان المكتب/المدينة ورابط الخريطة.
6. ربط نموذج التواصل بخدمة آمنة (البريد أو نظام استقبال طلبات)؛ النموذج الحالي واجهة فقط ولا يرسل البيانات.
7. مراجعة نصوص التعريف والإعلانات والمقالات للتأكد من دقتها والتزامها بالأنظمة وقواعد السلوك المهني.

## ملاحظات
- لا يتضمن الموقع ادعاءات عن عدد القضايا أو نسب النجاح أو الجوائز أو سنوات الخبرة.
- مجالات الخدمات والنصوص الحالية أولية وتحتاج اعتماد المحامية قبل النشر.
- لا تُرسل عبر النموذج الحالي بيانات قضايا أو مستندات سرية.
- الموقع لا يقدم استشارة قانونية مخصصة بمجرد التصفح.

## التقنية
HTML / CSS / JavaScript — دون إطار عمل أو قاعدة بيانات.


## استراتيجية المحتوى والأرشفة ومحركات البحث

### بنية المحتوى المستهدفة
- صفحة مستقلة لكل نظام أو لائحة.
- صفحة مستقلة لكل مادة نظامية، برابط ثابت قابل للمشاركة.
- صفحات شروحات ومقالات وأدلة إجرائية وأسئلة شائعة.
- تصنيف المحتوى حسب المجال والجهة المصدرة ونوع الوثيقة.
- إظهار المصدر الرسمي، ورقم/تاريخ الإصدار، وحالة السريان، وتاريخ آخر تحقق أو تحديث.
- الفصل الواضح بين النص النظامي المنقول والشرح التحريري.

### متطلبات SEO قبل الإطلاق
- عنوان ووصف فريدان لكل صفحة، مع عناوين HTML دلالية.
- روابط URL ثابتة وواضحة، وروابط داخلية بين النظام ومواده والمواد ذات الصلة.
- إعداد `sitemap.xml` و`robots.txt` بعد تثبيت عنوان النطاق النهائي وتفعيل الاستضافة؛ لا نضع رابطاً تخمينياً في خريطة الموقع.
- إضافة Canonical URL لكل صفحة بعد اعتماد النطاق النهائي لمنع تكرار النسخ.
- إضافة بيانات منظمة Schema.org مناسبة مثل WebSite وBreadcrumbList، وArticle للمقالات، مع تجنب بيانات مهنية أو عناوين غير موثقة.
- إعداد Open Graph وTwitter Cards لمشاركة الصفحات.
- تحسين سرعة التحميل، وتجربة الجوال، وإتاحة الوصول، وضغط الصور وتسميتها بنصوص بديلة.
- ربط النطاق بـ Google Search Console وBing Webmaster Tools، وإرسال خريطة الموقع ومتابعة أخطاء الفهرسة.
- عدم استخدام صفحات أو مقالات فارغة أو محتوى مكرر لمجرد زيادة عدد الصفحات.

### ضوابط المحتوى القانوني
- اعتماد النصوص من المصادر الحكومية الرسمية، مع حفظ رابط المصدر وتاريخ الاطلاع.
- توضيح أن الشرح تبسيط توعوي وليس بديلاً عن النص الرسمي أو استشارة قانونية خاصة.
- مراجعة التعديلات والإصدارات قبل تحديث المحتوى، وإظهار تاريخ المراجعة.
- عدم نشر استنتاجات أو فتاوى قانونية على أنها أحكام ملزمة.
- عدم نشر معلومات مهنية أو مؤهلات أو ترخيص إلا بعد التحقق والاعتماد.

### مراحل التنفيذ
1. تأسيس المكتبة والبحث والتصنيفات ومخطط بيانات الأنظمة والمواد.
2. إدخال الأنظمة ذات الأولوية من مصادرها الرسمية والتحقق من بياناتها.
3. إضافة الشروحات والمقالات والأدلة والروابط المرجعية.
4. إكمال SEO التقني، ثم النشر وربط أدوات مشرفي المواقع ومراقبة الفهرسة.

> ملاحظة: بيانات SEO الأولية موجودة في الصفحة الرئيسية. إعداد خريطة الموقع والروابط canonical والتحقق الفعلي من الفهرسة يتطلب اعتماد النطاق النهائي وتفعيل النشر العام.
